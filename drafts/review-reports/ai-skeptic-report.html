Edge-Case Stress Tests
AS-005
response_multiplier() computes a discarded branch that divides by zero
02b_behavioral_scenarios.py:127 · Edge-Case Stress Tests
LOW
What Was Claimed
The saturating form sat = 1 + (M-1)*eg / ((M-1) + eg) is "valid where eg > 0"; np.where(eg > 0, sat, lin) selects it.
What Was Found
np.where evaluates both branches for all elements, so sat is computed even for eg ≤ 0. When eg = −(M−1) (e.g., eps=0.5, g=−1, M=1.5 → eg=−0.5), the denominator (M−1)+eg = 0 and numpy raises a divide-by-zero RuntimeWarning producing NaN, which is then correctly discarded by np.where. The result is correct (PASS), but the warning is spurious and the pattern would become a latent bug if the branch condition were ever changed.
How It Was Verified
Executed temp/ai-skeptic-tests/test_fragile_ops.py (ECT-01); observed the RuntimeWarning with correct final values bounded at the ceiling.
What to Check
  • Compute sat only on the eg > 0 mask, or add a small epsilon to the denominator, to suppress the benign warning.
