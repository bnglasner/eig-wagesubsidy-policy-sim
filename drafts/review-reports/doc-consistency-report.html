CC-003
"Earning between $7.25 and $16.80" — $7.25 is a floor applied to all workers, and the upper bound is strict
drafts/2026-07-08_wage-subsidy-impact-cost-summary.md · Sample Definition
LOW
Document Claims
"The eligible population looks like the low-wage workforce … every paid-hourly worker earning between $7.25 and $16.80 per hour."
What the Code Does
# 02e_take_up_by_group.py (and mirrored in 02a):
base["employer_wage"] = base["hourly_wage_epi"].clip(lower=FED)   # FED = 7.25
recip = base[base["employer_wage"] < target]                     # target = 16.80 (strict <)
Why This Is Inconsistent
The $7.25 lower bound is not an exclusion criterion but a floor: a worker paid below $7.25 (e.g. tipped or sub-minimum) has their creditable wage clipped up to $7.25 and is included, not excluded. The upper bound is strict (< 16.80), so a worker at exactly $16.80 is excluded. "Earning between $7.25 and $16.80" reads as an interval membership test and slightly misstates both edges. The footnote's mention that the $7.25 base "blunts any incentive to misreport pay" hints at the floor, so the risk of misleading a careful reader is small.
What to Check
  • Consider "every paid-hourly worker whose employer wage is below the $16.80 target (with the creditable base wage floored at $7.25)".
  • Confirm the population of sub-$7.25 workers is small enough that the phrasing is immaterial.

Published Table 2 note omits the dependent-child exclusion applied to the denominator (and numerator)

Document Claims
"The denominator is the wage-observed hourly workforce; it excludes the self-employed and workers without a measurable hourly wage." (Table 2 note — the reader-facing description of the 134.3M base)
What the Code Does
# 02e_take_up_by_group.py:
base = org[epi_sample_eligible & hourly_wage_epi_valid & age.between(16,64) & earnwt>0]
base = base[~((base["relate"] == 301) & (base["age"] < 19))]   # dependent-child exclusion
recip = base[base["employer_wage"] < target]                     # numerator inherits the same exclusion
Why This Is Inconsistent
The base (and therefore the numerator) drops children of the householder under age 19 (relate == 301 & age < 19). The published Table 2 note lists only the self-employed and no-hourly-wage exclusions; the dependent-child exclusion is disclosed only in the internal "Evidence (strip before publication)" block. Because the exclusion is applied consistently to numerator and denominator the take-up rates are internally correct, but a published reader is not told the 134.3M base already removes teen dependents. Low risk, but a one-clause addition to the note would fully align text and code.
What to Check
  • Add "and dependent children under 19 living with a householder" to the Table 2 note's exclusion list.
  • Confirm the same exclusion is applied in 01a's construction of the 20.8M eligible base (recipient counts match 02e exactly, which implies it is).
