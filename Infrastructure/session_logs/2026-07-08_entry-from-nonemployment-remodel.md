## Key decision / framing
Read the two EIG Agglomerations pieces the user cited. Their thesis: the 80-80 subsidy should outperform the EITC on labor-force entry because it lacks the EITC's annual lump-sum payment, phase-out cliff, complexity, and categorical (child-conditioned) eligibility. Identified the core tension: `01h_nonemployed_pool.py::assign_reservation` calibrates induced-entry share to exactly equal `eps_ext_c x mean(gain)`, where `eps_ext` is EITC/CBO-derived (single_mothers 0.50 / other_women 0.20 / men 0.05) — mechanically importing the EITC's own participation ceiling (incl. near-zero for men) onto the instrument meant to break it. Noted `02d`'s wage-bargaining side already uses rich non-EITC structural theory (Mortensen-Pissarides, Hosios, Rothstein, etc.) — only the entry trigger is 100% EITC-derived.

## User correction (2026-07-08, same day) — M2 men-case reopened
User correctly identified a gap: the EITC's near-zero effect for men may be substantially a MECHANICAL household-composition artifact (credit scales steeply with number of qualifying children; near-zero for childless workers pre-1994 OBRA) — a sharper, more directly testable channel than the "salience/complexity" framing the first literature pass used, and one that maps directly onto the 80-80's actual structural difference (non-categorical, reaches childless men). Self-identified a real overreach: the first pass's use of Huttunen-Pirttilä-Uusitalo (2013) and Bonin-Kempe-Schneider (2003) as confirming "don't expect more male entry" was never checked for whether those programs were worker-facing vs. employer-side (demand-side hiring subsidies test a different mechanism entirely) or categorical vs. universal — so they may not be clean analogs. Dispatched a second targeted literature-scout pass (background) to: (1) verify what those two programs actually were, (2) find direct evidence on the household-composition channel via childless-EITC natural experiments (1993 OBRA, 2021 ARPA temporary expansion, state supplements) and noncustodial-father-targeted demonstrations (Parents' Fair Share and similar). Spec's M2 men-case numeric edge marked REOPENED pending this pass; mechanism resolution (band, not equality) stands.

## Second literature-scout pass results (complete)
- **Correction to Huttunen (2013):** confirmed employer-side (Finnish payroll-tax rebate) — downweighted as a caution either way; a demand-side hiring subsidy is not a clean analog to the worker-facing 80-80.
- **Correction to Bonin (2003):** confirmed WORKER-side and NON-categorical (worked example is a childless single person) via full primary-text read (IZA DP 587) — this is now a STRONGER caution than first credited: even a real non-categorical, worker-paid subsidy reproduced a null-to-negative male result, via a new mechanism not previously considered: intra-household coordination (subsidizing one earner can reduce a partner's hours). Not modeled anywhere in 02d (individuals treated independently) — flagged as an explicit out-of-scope limitation.
- **Paycheck Plus (MDRC RCT, the closest direct test of the user's hypothesis):** genuine split decision across two sites. NYC (Miller et al. 2018): real employment gains up to 5.8pp concentrated in disadvantaged men (noncustodial fathers, formerly incarcerated). Atlanta (Yang et al. 2022): zero effect for anyone. Parents' Fair Share (Miller & Knox 2001) reinforces: gains only for the LEAST employable men.
- **Cross-cutting insight:** responsiveness concentrates in a specific disadvantaged/noncustodial subgroup within "men," not men broadly. Likely not identifiable from CPS ORG/ASEC (no noncustodial-parent/justice-involvement variable) — noted as a disclosed limitation, NOT verified against data-dictionary findings, not committed as a build.
- 9 new/updated literature entries, catalog validated (62 entries, 0 warnings).

## Implementation plan drafted (2026-07-08)
Saved: `Infrastructure/plans/2026-07-08_entry-from-nonemployment-implementation.md`. Key design decisions worked out during drafting (not yet code, all flagged for user confirmation):
- **Band mechanism (M2):** cheap to implement — only the λ-solve (bisection) needs to run 3x per cell using the SAME deterministic per-person rank; the expensive Heckman/MPL imputation runs once, unchanged. Produces 3 reservation-wage columns.
- **Verify-before-calibrate discipline enforced:** checked the actual literature summaries for SSP (Card-Hyslop) and Paycheck Plus NYC — BOTH candidate anchor numbers are flagged `[unverified]` in their own summary files (secondary-source figures; primary MDRC/Econometrica tables were unreadable via fetch in the literature-scout passes). Made primary-source verification a hard prerequisite (Wave 2a) before any number is computed or wired into config — will not let plan-drafting momentum convert an unverified secondary number into a calibration input.
- **Net-of-transfer viability formula (M5) resolved:** compare NET GAIN of working vs. NET GAIN the reservation wage implies (both run through the same PolicyEngine schedule), rather than independently re-deriving a net reservation wage. Keeps r_i on its existing gross-wage-equivalent basis.
- **Confirmed reusable:** `01e_match_org_to_asec.py` already produces `asec_spouse_income` via a one-line sklearn NearestNeighbors (ball-tree) match — extending to the non-employed pool (new `01i_match_nonemployed_to_asec.py`) is a genuine reuse, not new machinery. Flagged as Tier 2 (nearest-neighbor on ~182k rows) needing a runtime estimate before running.
- **New config namespace proposed:** `cfg["matching"]["eps_ext_band"]`, separate from `cfg["behavioral"]["scenarios"]`, to avoid coupling 02b's untouched EITC/CBO-benchmark scenario table to 02d/01h's new band.
- **`other_women` cell:** no wage-subsidy-specific literature anchor exists (Card-Hyslop = single parents; Paycheck Plus/Parents' Fair Share = men). Proposed default: leave unchanged, labeled EITC/CBO-only. Flagged for user confirmation rather than invented.
